# Notices

The port uses the soloader boilerplate, so_util, FalsoJNI and vitaGL.
The port license and upstream notices are included with this package and in
its accompanying source archive. vitaGL is distributed under LGPLv3; its
COPYING and COPYING.LESSER texts are in licenses/. The matching vendored
source and port build files are included in the source archive.

This release requires the user's compatible Costume Quest game.apk and the
Vita runtime dependencies described in README.md. The original game data pack
and native game libraries are not included.
